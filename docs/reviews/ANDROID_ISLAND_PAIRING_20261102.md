# Android 灵动岛与免手填配对

本轮将 Android 的系统按钮页面改为 Mac 同款黑色岛体、薄边、薄荷绿音波、胶囊操作与记录/回忆/设置导航。App 和跨 App 悬浮窗共用 IslandPanel。悬浮窗只占岛体区域，点击展开/收起，180ms 宽度过渡；音波来自 MediaRecorder.getMaxAmplitude，暂停时归零。独立 IslandService 可在暂停录音后保留悬浮岛，用户可从常驻通知关闭；它不自行启动麦克风。首次需要系统悬浮权限；不申请无障碍或修改 SystemUI。

正常连接流程：新版 Mac 设置 → 连接 Android 手机 → 显示二维码并复制一次性链接 → 手机扫描或点开链接。手机自动兑换并保存设备凭据，不再手填服务地址、ID 或 Token。没有连接 Agent 时也可以先在手机本地记录；初次配对不会丢掉待传录音。

Mac 利用本机 Node、cloudflared 和已有 Super Agent profile，自动准备私有桥接、只开放手机路由的 HTTPS 网关、配对票据和 Source 安装。Source 通过本机权限受限的配置文件读取凭据，不要求用户修改宿主进程环境变量。已有宿主未就绪时停止安装，显示实际状态，不强制重启宿主。生成的配对票据仅有效 120 秒、一次性使用，不携带 Agent/ASR 凭据。快速隧道经 Cloudflare 转发 HTTPS 流量，依赖当前 Mac 和隧道运行，后续正式部署可替换为固定 HTTPS 服务。

## 验证

- 15 项桥接/配对/网关测试通过。涵盖一次性兑换、重放拒绝、非 Agent 无权生成链接、手机不能访问 Agent/ASR 路由，以及手机配对和 Agent 连通状态分开。
- 3 项现有 Super Agent 实际注册与 Policy 契约测试通过。
- 实际 HTTPS 配对回执 200；凭据与本机设备配置一致；同票据重放 410；公网访问 `/v1/events` 返回 403。测试没有上传真实录音。
- 现有 Super Agent 已热加载 `agentone-context`，实际健康条目为 ready，收到 0 个证据事件，未创建真实任务。没有重启主宿主或改全局执行策略。
- Mac Swift 编译、Release ZIP 打包和原有真实包校验通过。包含配对组件、Source、二维码入口；此结果不代表已替换当前运行 App。
- Android APK 编译并验签通过，原型版本 0.1.1（versionCode 2）。
- 独立无窗口 Android 模拟器实际展示了新 UI，未见 App Java 崩溃；系统自身出现 System UI ANR，因此没有把截图作为正常运行验收。测试脚本从 shell 启动未导出录音 Service 被 Android 拒绝（正确的权限隔离），录音和悬浮窗交互仍须经 App 操作及真机验证。临时模拟器已清理，未调用真实设备麦克风或抢占桌面。

## 保留的边界

配对/Source 连通不等于模型已识别任务或完成真实交付。未自动扩大现有项目 Policy、未打开所有推断规则的执行权限。手机声纹录入、真实手机系统兼容、完整语音任务验收和即时推送仍属后续工作。当前通知采用轮询。新的二维码界面需使用本轮构建的 Mac App；当前运行进程未被重启。
